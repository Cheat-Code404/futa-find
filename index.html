How FUTA Find works

1. Browse Lost and Found listings without signing in.

2. Post an item with its details and a WhatsApp number.

3. Anyone interested can tap Contact on WhatsApp to message the poster directly.

4. When an item is back with its owner, mark the listing Returned.

5. Meet in a busy public place on campus and avoid sharing sensitive personal information.

This prototype is not connected to a live backend yet. Firebase configuration, security rules and admin setup are included in the project download.
